## 1. The making-verb hook is confirmed (now a gate)

Every hook since Case File 59 whose first sentence names what the smugglers MADE skipped at 16–23 %; every hook that led
with a quantity skipped at 28–34 %. `pipeline/engage_qa.py` now checks `hook_making_verb` for engagement_version 9: the
first sentence is ≤ 8 words, contains a making verb (built, turned, dressed, stamped, sewed, glued, hollowed…) and has
no digit or number word. The number goes in the second line. Replayed on 92–97: passes 92, 94, 95, 96, 97; fails 93
(the only one of the six above 30 % skip on a 23 % day).

The shot-size classifier in pipeline/shot_manifest.py sizes shots by figure scale, so all six openings score "wide": it
cannot see this. So it stays the owner's reviewer's question on the saved frame-0 still, in this form: **is the object
being opened by hands, close, with the inside still hidden?** A pile, a vehicle at rest, or a thing already open fails.
The reveal must complete on the gotcha line (≤ 9 s), so the hook scene carries a prop key on that line.
